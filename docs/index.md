# Welcome to 13Repository | 8ARMS

13號倉庫提供專為特殊零組件存放服務  
> 只負責零件供給，不提供技術詢問服務

## 使用方法

定期更新倉庫物品資訊、與庫存狀態，初次使用請按照下方步驟

1 加入倉庫管理員LINE帳號 - @387uhazm  
2 輸入[驗證碼] - 驗證碼輸入後管理員提供對應倉庫網址  
3 輸入零件編號 - 每一項零件都有特定編號  
4 確認庫存、交期情況 - 等待管理員查看系統  
5 支付零件費用 - 確認後提供支付截圖資訊或匯款帳號後5碼  

## 注意事項

倉庫內皆為客戶暫存零件，當有剩餘庫存才允許對外供給  
如目前無庫存，需等待下批入庫後再發消息通知
